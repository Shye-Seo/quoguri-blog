11월 한 달에만 새 모델이 열 개 넘게 나왔어요. 11월 9일 Claude Fable 5.2, 17일 GPT-6.2 Astra·Sol, 18일 Gemini 4 Neon까지. 뉴스만 따라가면 "이번 주 1위는 또 바뀌었네"로 끝나요.

그런데 "지금 제일 좋은 모델이 뭐예요?"라는 질문은 사실 답이 없어요. **벤치마크 1위 모델이 내 업무에서 1위라는 보장이 없고**, 무엇보다 그 1위는 비용이 몇 배인 경우가 많거든요. 그래서 이 글은 순위를 알려주는 글 대신, **내 작업 기준으로 다시 정리한 표**예요.

먼저 밝혀 둘게요. 이 글은 제가 세 모델을 같은 조건에서 직접 시험한 기록이 아니에요. 공개된 벤치마크(Artificial Analysis 지능 지수 v5.0.1)와 각 회사 공식 문서·가격표를 **내 작업 기준으로 다시 읽은 정리**예요. 마지막 판단은 직접 써보고 하는 게 맞고요.

## 11월에 나온 모델, 한 표로

토큰 단가는 100만 토큰당 입력 / 출력 가격이고, 점수는 Artificial Analysis 지능 지수(괄호는 추론 강도 설정)예요. 과제당 비용은 그 설정에서 작업 1건을 처리할 때 드는 평균 API 비용이에요.

| 모델 | 단가(입력/출력) | 지수 · 과제당 비용 |
| --- | --- | --- |
| Claude Fable 5.2 (11/9) | $8 / $40 | 64.6(max) · $26.54, high 61.8 · $9.08 |
| GPT-6.2 Astra (11/17) | $8 / $40 | 62.1(max) · $4.00, high 60.1 · $2.07 |
| GPT-6.2 Sol (11/17) | $2 / $10 | 57.3(max) · $1.01, high 54.9 · $0.56 |
| Gemini 4 Neon (11/18) | $3 / $15 | 61.4(xhigh) · $6.44, high 59.6 · $3.74 |
| Gemini 4 Hydrogen (11/12) | $1.50 / $7.50 | 53.9(xhigh) · $3.16, high 50.8 · $1.87 |

숫자만 보면 Fable 5.2가 압도하는데, high 설정에서 과제당 비용이 $9.08이에요. GPT-6.2 Astra는 점수가 4점 낮은 대신 $2.07이고요. **4배 넘게 싼데 점수 차이는 4점**이에요. 이 4점이 내 업무에서 의미가 있는지가 진짜 질문이에요.

## 벤치마크를 읽을 때 꼭 붙는 세 가지

**① 같은 모델도 설정에 따라 점수가 다르다.** 위 표의 괄호가 '추론 강도'예요. 모델이 답하기 전에 얼마나 오래 생각할지 정하는 값이고, low부터 max까지 있어요. GPT-6.2 Astra는 low 45.7점에서 max 62.1점까지 벌어져요. "Astra 점수"라고만 말하면 말이 반쪽이에요.

**② 1~2점 차이는 순위가 아니다.** 이 지수는 9개 벤치마크를 가중 평균한 값이에요. 평가마다 오차가 있고, 1~2점 차이로 "더 좋다"고 말하기는 어려워요. 실무에서는 5점 단위로 묶어서 같은 구간 안에서 **가격**을 비교하는 편이 낫다고 해요.

**③ 평가 항목마다 1등이 다르다.** 이게 제일 중요해요.

| 평가가 재는 것 | 내 업무로 치면 | 점수 1위 |
| --- | --- | --- |
| AA-Briefcase | 자료 모아 보고서·분석문서 만들기 | Fable 5.2 (Astra보다 82% 비쌈) |
| FrontierCode 2.0 | 기존 코드 고치는 작업 | Fable 5.2 49.1% (Astra 47.1%) |
| Terminal-Bench 4.0 | 터미널·운영 자동화 | Gemini 4 Neon 61.6% |
| GDP.pdf | 계약서·긴 보고서 읽고 답하기 | Gemini 4 Neon |
| AA-Omniscience | 사실 정확성이 중요한 질의응답 | Fable 5.2 (Astra와 17점 차) |
| AA-Briefcase 비용 | 같은 작업을 싸게 | GPT-6.2 Astra (점수는 6% 낮음) |

재밌는 건 FrontierCode예요. Fable 5.2가 1등인데 2%p 차이이고, 비용은 3배 넘게 차이 나요. 이런 경우엔 **싼 쪽으로 충분한지 먼저 시험해 보는 게** 합리적이에요.

## 상황별로 고르면

제가 실제로 나눠 쓰는 기준이에요. 모델 이름보다 "무슨 일이냐"로 먼저 고르면 덜 헷갈려요.

| 이런 일 | 추천 | 이유 |
| --- | --- | --- |
| 긴 글 다듬기, 문체 맞추기 | Claude 계열 | 긴 문장 흐름과 어조 유지가 강점 |
| 자료·영상 분석, 구글 문서 연동 | Gemini 계열 | 영상 업로드·Drive 연결이 편함 |
| 여러 작업을 한 화면에서 | ChatGPT | 이미지·리서치·데이터를 한 흐름으로 |
| 코드 수정·테스트 | Claude Code / GPT-6.2 | 코드 평가 점수 상위, 도구 붙이기 쉬움 |
| 대량 처리, 비용이 중요 | GPT-6.2 Sol / Gemini 4 Hydrogen | 단가가 낮고 점수도 실무 하한 이상 |
| 정말 어려운 한 문제 | Fable 5.2 (max) | 최고점, 대신 한 건에 $26대 |
| 무료로 먼저 써보기 | Gemini 4 Hydrogen | 무료 등급 API와 검색에 열려 있음 |

표에 없는 것도 있어요. **Gemini 4 Carbon은 점수가 높지만 "일부 지역의 검증된 기업 고객" 대상**이고, Anthropic의 Mythos 5.2는 검증 조직만, OpenAI의 GPT-6 Cyber도 승인 고객만 써요. 뉴스에서 본 모델이 내 계정에 안 보이면, 대개 이 이유예요.

## 서비스로 고르기 (앱 요금 기준)

모델은 API 단가로 비교했지만, 우리가 실제로 쓰는 건 앱이에요. 2026년 11월 한국 앱스토어 기준 개인 요금제예요.

| 서비스 | 강한 곳 | 월 요금 |
| --- | --- | --- |
| ChatGPT | 이미지 생성, 자료 조사, 파일 분석을 한 번에 | 29,000원 |
| Gemini | Gmail·Drive·YouTube 연동, 가족 공유 | 29,000원 |
| Claude | 글쓰기, 코드, 긴 문서 작업 | 33,000원 |

요금은 거의 비슷한데 **잘하는 일이 달라요.** 셋 다 결제할 필요는 없고, 내가 일주일에 제일 많이 하는 작업 하나를 기준으로 고르고, 나머지는 무료로 쓰는 편이 낫다고 봐요. 저는 결제는 한 곳만 하고, 나머지는 필요할 때 한 달씩 끊는 쪽이에요.

## 주의할 것 두 가지

1. **12월 1일 단가 변경** — Gemini 4 Carbon과 Argon의 도입가($2/$10)가 끝나고 $4/$20로 올라요. 11월에 본 가성비 표를 12월에 그대로 믿으면 안 돼요.
2. **발표일과 사용 가능일은 다르다** — 모델은 발표 → 미리보기 → 일반 공개 순서로 열려요. Fable 5.2도 발표 당일부터 유료 요금제와 API에서 쓸 수 있었지만, 모든 모델이 그렇지는 않아요.

## 마무리

정리하면 이렇게 골라요.

- **글·코드 품질이 최우선** → Claude 쪽, 비용은 감수
- **자료·영상·구글 연동** → Gemini
- **이것저것 한 번에** → ChatGPT
- **싸게 많이** → GPT-6.2 Sol, Gemini 4 Hydrogen
- **결정 못 하겠으면** → 내 작업 3개로 직접 비교
